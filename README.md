## 📌 Featured Projects

### 🔍 Merchant Risk Ranking System

End-to-end **PySpark ETL and machine learning pipeline** processing **13M+ transactions and 500K+ consumer records**, integrating external socio-economic data to build merchant risk rankings and predict fraud likelihood and revenue stability.

### 🚕 NYC Yellow Taxi Fare Prediction

Processed **34M+ taxi records** using PySpark, engineering temporal, geospatial, holiday, and weather features. Trained and tuned regression models using time-series cross-validation, achieving approximately **$2.00 RMSE for fare prediction**.

### 🤖 Cascade AI — Minimax Game Agent

Built a **Minimax-based game-playing agent** and iteratively refined its decision-making strategy through experimentation and testing. Competed against **206 student-developed agents**, achieving **59th place**.

### 🚦 German Traffic Sign Recognition

Built a machine learning pipeline to classify **43 traffic sign categories** from 5,488 images using HOG feature extraction, PCA, SVM, Random Forest, and KNN. Achieved **94.5% Kaggle test accuracy** with a tuned SVM.

### 🏥 Scheduling of Care Website

Developed a **multi-role MERN web application** with React dashboards, JWT authentication, email verification, and role-specific functionality. Worked in an Agile team using bi-weekly sprints, stand-ups, and peer code reviews.

### 🌦️ Sky Watching Weather Website

Built a full-stack weather application during a **hackathon**, combining NASA weather and astronomy APIs to provide location-based information for astronomical events such as shooting stars, auroras, and clear-sky conditions.

### 🚕 Taxi Trip Recommendation System

Developed a data-driven taxi recommendation system using **PySpark**, combining taxi trip data with weather information to identify patterns and recommend suitable trips based on location and conditions.

### 💳 BNPL Strategy & Revenue Analysis

Analysed Buy Now, Pay Later business data to identify revenue trends and growth patterns. Compared **ARIMA, ARIMAX, and XGBoost** approaches before selecting a growth-based approach to support business recommendations.
